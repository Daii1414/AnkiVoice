## [1.2.0] — 2026-10-20

Установщик: `AnkiVoice-Setup-1.2.exe` · релиз: <https://github.com/Daii1414/AnkiVoice/releases/tag/v1.2>

### Добавлено

- **Мастер первого запуска** — четыре шага: папка GPT-SoVITS, AnkiConnect,
  сервер, тестовая фраза. Показывает, что именно не так, и даёт конкретные
  инструкции: что скачать, куда распаковать и что нажать.
- Мастер открывается сам при каждом запуске, пока настройка не завершена.
- **Проверка обновлений** на вкладке «Приложение»: changelog последнего
  релиза GitHub, скачивание установщика и **обязательная** проверка SHA256
  (без хэша в релизе скачивание запрещено). Перед запуском установщика хэш
  проверяется ещё раз.
- **Живая диагностика** в мастере: статусы движка, Anki, сервера, голосов и
  тестовой фразы.
- Чип с версией в шапке интерфейса.
- `selftest` и `doctor` теперь печатают статус модулей системы чтения и QC v2.
- **Установщик везёт подсистемы чтения**: 5 модулей из `lab/` (provenance,
  доменный словарь, генератор кандидатов, резолвер, QC v2) кладутся в
  `{app}\lab`. Раньше они не попадали в установщик, и установленное приложение
  молча работало на простом критерии «есть звук» без доменного словаря.
- Тест `lab/test_v12_features.py` в CI: версии, парсинг релиза, SHA256,
  защита от повторного скачивания, состав установщика, логика мастера.

### Исправлено

- Мастер настройки больше не открывается «на автомате» после первого
  закрытия: флаг `avWizardSeen` в `localStorage` отключал автопоказ навсегда.
- Скачивание обновления сериализовано: фаза `checking` ставится до сетевого
  запроса, поэтому два быстрых клика не запускают два потока в один файл.
- `lab/g2p_candidates.py`: `del` несуществующего имени при неудачном импорте
  `haqumei` ронял импорт всего модуля (`NameError`); жёсткий путь
  `E:\TTS-проект\lab\pylibs` заменён на путь относительно файла.
- Завершённость настройки определяется только явным флагом `setup_done`:
  старый тестовый файл больше не «подтверждает» новую папку движка.
- «Озвучить N карточек» теперь означает N карточек **работы**: лимит выбирает
  карточки, где звука ещё нет (поиск `deck:"…" -Поле:*sound*`), а не первые N
  в колоде. Раньше на почти озвученной колоде приложение отвечало «всё уже
  озвучено», хотя не озвучено ещё сотня.
- Озвучка больше не уходит с пустыми именами полей: берутся сохранённые
  настройки, а если их нет — автоподбор по полям выбранной колоды. Поля
  подставляются сами при смене колоды.
- В узком окне (< 900 px) вкладки не исчезали: сайдбар превращается в
  горизонтальную панель, страница не прокручивается вбок.
- Баннеры различают «озвучивать нечего», «остановлено по кнопке», «проверка
  нашла проблемы» и обычную ошибку — раньше всё выглядело как «Готово».
- `AnkiVoice.iss` больше не зависит от жёсткого пути — сборка одинаково идёт
  локально и в CI.

### Документация

- README переписан: логотип, бейджи, оглавление, раздел «Что нового в 1.2».
- Скриншоты интерфейса пересняты (вкладка «Приложение» и мастер настройки).
- `CHANGELOG.md`, `CONTRIBUTING.md`, `SECURITY.md`, шаблоны issue и pull request.
- Из репозитория убраны мёртвые скрипты и отчёты, которые никто не читал.

## [1.1.0] — 2026-10-20

Установщик: `AnkiVoice-Setup-1.1.exe` · релиз: <https://github.com/Daii1414/AnkiVoice/releases/tag/v1.1>

### Добавлено

- **QC v2** — многосигнальная проверка качества синтеза: долгое молчание,
  разрывы внутри речи, дубль речи, обрезка, уровень, скорость мор/с. Разные
  пороги для слова и предложения.
- Контроль качества звука: мусорная тишина не попадает в колоду, брак
  перегенерируется автоматически.
- **Система чтения с фуриганой-приоритетом** и доменным словарём: фуригана
  карточки читается из полей Anki и подставляется в конвейер.
- Локальный веб-интерфейс вместо tkinter-окна (окно осталось под `--classic`).
- Релиз — один установщик на Inno Setup 6, профильная установка без UAC.
- Полный английский README.

### Исправлено

- `ffmpeg_exe` не падает, если папки движка нет.
- CI: ffmpeg для аудио-интеграции.
